2What FlameMind is

FlameMind is an AI web dashboard. It turns NASA microgravity combustion research into fire-safety insights, with a source cited for every claim, for places where people will live beyond Earth: Moon bases, rovers, spacecraft, and space stations. Rockets and propellants are out of scope.

The ground rules

  • Every data claim cites a source, with a DOI when one exists. If there is no evidence, the app says "Insufficient evidence in the PSI data."
  • Suggestions are labeled as suggestions. Each one names the findings it relies on and carries the note "Research summary, not certified safety guidance."
  • Unknown values stay empty (null) and are never guessed.
  • Science data lives in committed JSON files in data/, never in a database. User accounts, if added later, store only profile, chats, and saved filters.
  • Model names and cloud settings come only from environment settings (.env), never from the code itself.

The planned experiences (not built yet)

Scenario chat

Describe a situation, for example "a fabric fire in a lunar habitat." The app shows the relevant data and, only when you describe a use case, labeled suggestions with sources. Signed-in users can save chats.

Explore

Manual filters, search, and a "custom filter" written in plain English that the same AI turns into real filters. Results always appear as a table, and filter sets can be saved.

7AI extraction (schema.py and extract.py)

This step turns the clean text into one structured record per investigation, using Google's Gemini model on Vertex AI. The record has the exact fields you specified: hardware, platform, years, fuels, sample size, oxygen, pressure (in both kPa and psi), and flow ranges, plus gravity, diluents, the variables that were varied and held fixed, sensors, a list of tests, and findings on ignition, flame spread, and extinction. It ends with key findings, fire-safety relevance, sources, and a needs_review flag.

The safeguards

SafeguardWhat it does
Fixed answer formatGemini must answer in the exact record shape, which is enforced through the schema.
Strict instructionsUse only the given text. Leave unknowns empty. Never guess. Give a page reference for every number and finding.
Real page numbers onlyEvery citation must point to a file and page that were actually in the text. Otherwise the answer is rejected and retried.
One retry, then flagA failed answer is sent back once with the error. If it fails again, bad parts are dropped and the record is marked needs_review.
Unit checkPressure is filled in both kPa and psi. If the two don't match, the record is flagged.
Range checkFlags pressure of zero or below, oxygen outside 0–100%, a minimum above its maximum, and tests outside the stated range (ignoring tiny rounding differences).
Exact test countEach group of table rows must return exactly one test per row.
Rate-limit handlingWhen Google says "too many requests," it waits 15, 30, 60, then 120 seconds and retries. A call that still fails becomes a review reason instead of a crash.
Saved answersRaw answers are stored in data/cache/extract/, so finished investigations aren't redone unless you add --force.

Options

.venv/bin/python extract.py --only BASS,FLEX    # pick investigations by short name or NASA ID
.venv/bin/python extract.py --force             # redo even if a saved answer exists
.venv/bin/python extract.py --no-tables         # skip the per-row test pass
.venv/bin/python extract.py --rows-per-call 40  # table rows per Gemini call

BASS: Burning and Suppression of Solids

  • Where: Microgravity Science Glovebox (MSG) on the ISS, 2009–2013
  • Fuels (solid): cotton-fiberglass fabric, Nomex, Ultem, PMMA, wax, Japan wax, paraffin
  • Shapes: flat sheets, solid spheres, candles in tubes
  • Conditions: oxygen 21%, airflow 0–44 cm/s, nitrogen as the extinguishing gas, no pressure stated
  • Sensors: still and video cameras, hot-wire anemometer, radiometer
  • Tests: 122 from the test-run table (date, test number, sample, material), plus 11 from the fabric paper with flow speeds and spread rates. For example, sample 7 at 10 cm/s spread steadily at 2.55 mm/s.
  • Findings: concurrent-flow spread rate rises in a straight line with flow speed. Opposed-flow spread peaks at about 10–15 cm/s. The flame quenched at about 1 cm/s. The fabric burned in opposed flow in microgravity, where in normal gravity it puts itself out.

FLEX: Flame Extinguishment Experiment

  • Where: Multi-user Droplet Combustion Apparatus (MDCA) on the ISS, 2007–2016
  • Fuels (liquid droplets, 1.1–4.67 mm): methanol, heptane, octane, decane, butanol, biofuels, Jet-A, gasoline, and others
  • Conditions: oxygen 12–34%, pressure 50.7–309.3 kPa (7.3–44.9 psi). Diluents: CO₂, He, SF₆, N₂, xenon.
  • Tests: all 274 table rows. 186 ended in extinction. 88 ended in "Disruption," which is recorded as "unknown" with the original wording kept in the notes.
  • Data issue handled: test 114 records pressure as 0 mmHg, a recording error. That pressure is left empty with an explanatory note.
  • Findings: methanol droplets burned 40–70% faster in normal gravity than in reduced gravity. Droplets kept burning with 50% xenon but not with 50% helium or CO₂.
Things to know about these records:
  • Some FLEX fuels, such as gasoline, Jet-A, camelina, and tallow, come from publication titles that have no abstract.
  • One FLEX finding is about a spinning polymer disc. NASA lists that paper under FLEX, but it isn't a droplet experiment.
  • Gemini's answers vary slightly between runs. For example, BASS's sample size and ignition finding were filled on one run and empty on another.

InvestigationOne NASA research project, such as BASS or FLEX, with an ID like PSI-26.

Concurrent / opposed flowAir moving with the flame's direction of spread, or against it.
DiluentA non-burning gas such as nitrogen, CO₂, or helium, used to slow or stop a flame.
DOIA permanent ID for a paper or dataset, used for citations.
Vertex AI / GeminiGoogle Cloud's AI service, and the AI model it runs.
EmbeddingA list of numbers capturing what a piece of text means, used for search by meaning.
SchemaThe exact shape a data record must have.
needs_reviewA flag saying a person should double-check a record.
Rate limit (429)Google's cap on how many AI calls a project can make per minute.
